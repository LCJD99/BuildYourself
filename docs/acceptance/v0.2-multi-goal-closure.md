# v0.2 多目标与跨周闭环验收记录

## 可复现的受控 HTTP 验收

运行：

```sh
npm test -- tests/v2-multi-goal-acceptance.test.ts
```

该测试使用独立 SQLite 文件并通过各 HTTP 路由注入可控 Agent 结果。它从两个目标开始，确认共享行动只在日视图出现一次且关联双方属性；提交部分完成反馈并重试同一幂等键；记录有收益计划外行动和零贡献杂项；随后复盘、调整并确认下周规划，读取旧周状态，并对延续的同一行动提交新反馈，检查属性贡献只增加尚未记录的部分。所有重读均通过公开 HTTP 查询路由完成，不依赖先前对话对象。

这组受控结果验证业务状态转换、持久化和 API 关联，不评价 Agent 的自然语言判断质量。

## 真实 Agent 联调

现有真实 PI 烟测分文件验证目标澄清、首周规划、计划内反馈、计划外反馈和周复盘。可运行：

```sh
RUN_PI_AGENT_SMOKE=1 npm test -- tests/goal-drafts-live-smoke.test.ts tests/weekly-plans-live-smoke.test.ts tests/action-feedback-live-smoke.test.ts tests/weekly-reviews-live-smoke.test.ts
```

这些烟测验证各 Agent 调用链能返回并保存可读取结果；它们不是上面整条双目标闭环的真实模型验收，也不证明模型判断或属性贡献质量。真实双目标场景的可复现业务验收由受控 HTTP 测试覆盖。

本次运行结果（2026-11-24）：4 个 smoke 文件中 3 个通过、1 个失败。周规划、计划内及计划外反馈、周复盘真实 PI 流程通过；目标草稿 follow-up 有一次输出了无法识别或为空的约束项，API 按协议返回 502。该结果表明四个 Agent 路径尚未全部稳定通过；不能据此宣称真实模型已完整完成多目标闭环验收。
