# BuildYourself

BuildYourself 是本地单用户目标规划原型。pi Agent 将自然语言目标整理成可编辑的目标契约；SQLite 保存草稿、启用目标、里程碑、证据要求和近期行动。浏览器显示已确认的目标与待排行动。聊天记录不是权威数据。

## 启动

需要 Node.js 22.13 或更新版本，以及已安装并配置模型的 pi agent。

```sh
npm install
npm run dev
```

打开 http://localhost:3000。另开终端，在项目目录运行：

```sh
pi -e ./pi/goal.js -e ./pi/evidence.js
```

### 从自然语言创建目标

在 pi 里直接输入「我想学英语」，或使用 `/goal 我想学英语`。Agent 只会追问会改变计划的场景、预期结果、当前基础和关键限制。基础未知时，它会建议一项基线行动。之后会生成成功描述、可观察结果、里程碑、近期行动、约束、证据要求和复盘周期，并说明里程碑标准与证据可获得性的评估。远期阶段可以保留为待细化的里程碑。

Agent 将计划保存为草稿后，可以按对话要求修改。契约未通过校验时保持草稿，不会进入规划。用户明确确认后，pi 会再次弹出启用确认；浏览器也可在计划完整时点击「核对并启用」。启用后，具体近期行动进入「待排」池，不会自动编排日期或时段。

浏览器中的「自然语言目标计划」区域展示草稿的校验缺口、活跃目标的成功标准、里程碑核对、证据要求、限制、复盘周期和待排行动。

活跃目标可以暂停或申请完成。暂停会保留目标和待排行动历史，并从待排池移除；恢复时重新检查 10 个活跃目标上限。申请完成需要逐项提交证据说明和等级，满足目标契约的最低等级后仍需用户单独确认。归档和放弃目标时必须填写原因，所有状态变更及完成证据都保存在状态记录中。

### 记录文本证据

在 pi 中使用 `/evidence`（也可输入 `/evidence 反馈原文`）。选择当前对象和其他关联对象，填写证据原文、来源、引用和时间，选择证据等级，并核对报告提交与测量字段后确认保存。浏览器会显示执行状态、证据充足度、交付验收和里程碑结果。完成行动不会自动改变里程碑判定。

## 数据与验证

数据默认保存在 `data/graph.sqlite`；可通过 `BUILDYOURSELF_DB` 指定绝对路径。`BUILDYOURSELF_URL` 可指定 pi 连接的本地应用地址。

```sh
npm run typecheck
npm test
npm run build
```

原型面向可信的本机环境运行，尚未提供远程访问认证。当前目标计划功能不会自动分配日程；近期行动只会等待后续日级规划流程。
