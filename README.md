# BuildYourself

本地单用户原型：通过 pi agent 录入一份文本证据，在浏览器分别查看交付与里程碑判定。图谱保存在本地 SQLite，聊天记录不是权威数据。

## 启动

需要 Node.js 22.13 或更新版本，以及已安装的 pi agent。

```sh
npm install
npm run dev
```

打开 http://localhost:3000。另开终端，在项目目录运行：

```sh
pi -e ./pi/evidence.js
```

在浏览器选择当前目标、任务或里程碑，在 pi 输入 `/evidence`（也可输入 `/evidence 反馈原文`）。确认当前对象，按需选择其他关联，填写原文、来源、引用和时间，并核对报告提交与测量字段，最后确认保存。浏览器约 3 秒内刷新结果。可以在 pi 中更改当前对象；更改不会依赖聊天上下文。

试用：选择「提交测试报告」，在 pi 同时关联里程碑，输入「测试报告已按要求提交，完整基准测试测得延迟 230 ms」，确认报告已提交、完成完整基准测试、延迟为 230。右栏显示交付已验收、里程碑本次实测未达标。只提交报告时，在相应核对项选择未说明并留空测量值，里程碑显示缺少测量。

数据位于 `data/graph.sqlite`；可通过 `BUILDYOURSELF_DB` 设置绝对路径。`BUILDYOURSELF_URL` 可指定 pi 连接的本地应用地址。请只在可信的本机环境运行；该原型没有远程访问认证。反馈中的结构化事实由用户在 pi 核对，规则不会从任意自然语言推断事实。通过标准的里程碑只显示待确认，当前阶段尚未实现确认达成和证据更正。

```sh
npm run typecheck
npm test
npm run build
```
